Applying for FSBench-40K

FSBench-40K is made available through an application to the corresponding author. The repository presents the project and selected examples; full image archives are delivered separately.

Before applying

Read the data use conditions. Complete the application PDF, using a desktop PDF reader if browser form saving is unavailable. Save the completed file, reopen it to verify the entries, and sign the declaration. A completed form does not itself grant access.

Information required

  • Applicant, institutional affiliation, research contact and institutional profile if needed.
  • Responsible researcher or supervisor and every person who will access the images.
  • Project purpose, planned methods, intended outputs and requested access period.
  • Requested dataset version, or a request for the release associated with the paper.
  • Storage, access control, cloud processing and intended data retention arrangements.
  • Any planned commercial use, redistribution, image publication or other permission requiring separate review.
  • Applicant and responsible researcher declarations. Independent researchers may explain their status and sign both roles.

Use an attachment if more team-member rows or project space are needed, and identify each attachment in the application.

Submission and review

Email the signed form to Haicheng Qu, quhaicheng@lntu.edu.cn, using the subject FSBench-40K Data Access Request — Institution — Applicant. Do not place completed forms in a public issue or pull request.

The corresponding author reviews the research purpose, applicant information, requested access and applicable source permissions. Clarification may be requested before a written decision. Access is not conditional on favourable results or co-authorship.

Approved delivery

The written approval identifies the authorised project and users, approved use, release identifier and access conditions. Delivery includes the image archive, class definitions, split manifests, integrity hashes and release documentation. Recipients should verify the checksums, record the version and retain the approval with their research records.

For reproduction of the paper, request its corresponding fixed release and supplied splits. A later release or a custom split should be identified separately in reported results.

Changes after approval

Contact the corresponding author before changing the project purpose, approved users, institution, external processing arrangements or access period. Report suspected data issues using image IDs and the release identifier.

Application information

Information in the form is used to review the request, administer access and communicate with the research team. Send corrections or access-record queries to the corresponding author. The blank form asks for research identity and project information, not passwords, identity documents or payment details.
